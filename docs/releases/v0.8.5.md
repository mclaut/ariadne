# Ariadne v0.8.5

This patch release closes two publication-time gaps without changing the
approval scopes or storage format introduced in v0.8.4.

## Foreground macOS approval warnings

- The native macOS warning now activates before `display dialog`, preventing a
  new access request from remaining behind the active coding window.
- Visibility is not authority. Approve, Deny, Later, close, expiry, session
  scope, collection scope, and one-shot consumption keep their existing
  fail-closed semantics.
- A regression test requires activation to occur before the dialog is shown.

## Hugging Face publishing

- The Space `short_description` now satisfies the Hub's 60-character metadata
  limit.
- The Space release copy and links identify v0.8.5 while preserving the full
  v0.8.4 project-isolation and human-approval explanation.

## Verification

- macOS approval-script ordering test
- full Go race suite, build, and lint
- Windows and Linux cross-builds
- clean production builds for GitHub Pages and Sites
- Hugging Face metadata length and static-source validation
- working-tree, history, and secret-pattern privacy scans
