# Ariadne v0.8.12

This reliability release bounds scheduled maintenance, makes schema-bound
consolidation deterministic for reasoning-capable Ollama models, and adds a
strictly scoped, append-only credential-trust policy for owner-approved repeat
work.

## Fixed

- **Scheduled maintenance is bounded.** The maintenance supervisor now defaults
  to 20 minutes, close to consolidation's own 15-minute deadline. A child that
  stops observing cancellation therefore cannot retain the daily scheduled job
  for hours.
- **Consolidation stays schema-valid with reasoning-capable models.** Requests
  for consolidated memories and verdicts explicitly set Ollama's `think` flag
  to `false`, so the response is the required JSON object rather than a
  reasoning trace followed by output.

## Added

- **Exact persistent credential trust.** `ariadnectl credential trust` records
  an owner-approved, exact source-wing, target-wing, resource, and purpose
  policy. A matching `credential_access` call proceeds without another popup,
  but creates an immutable use audit record.
- **Append-only revocation.** `ariadnectl credential revoke` appends an exact
  revocation event. It disables only that policy tuple and preserves every prior
  trust and use record for audit.

## Compatibility

- Existing one-time credential grants remain supported and default-deny.
- Persistent trust authorizes policy only; Ariadne never reads, returns, stores,
  or logs the credential value.
- Existing scheduled maintenance can keep its explicit timeout. New installs
  receive the 20-minute default.

## Verification

- focused Go tests for credential trust, revocation, MCP access, consolidation
  request payloads, and maintenance timeout defaults
- Go build and macOS launchd plist validation
- English and Ukrainian site build plus rendered-page tests
