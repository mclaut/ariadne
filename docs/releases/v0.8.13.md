# Ariadne v0.8.13

This reliability release makes bounded consolidation honest under local-model
load: a deadline is safe deferred work rather than a false maintenance failure.

## Fixed

- **Consolidation deadlines no longer turn maintenance unhealthy.** Batches
  that remain after the bounded curator deadline are safely deferred, so the
  maintenance supervisor does not repeat the entire stage three times.
- **Deferred lifecycle metadata is persisted after model work ends.** Ariadne
  uses a fresh short persistence context to record the append-only deferred
  markers, preserving every source diary for a later curator pass.

## Compatibility

- Source diary text and vectors remain active and intact whenever work is
  deferred.
- `complete_with_deferred` remains a healthy maintenance outcome; the tray
  continues to warn for actual partial, failed, stuck, or stale work.

## Verification

- focused regression test for deadline classification
- full Go tests, build, lint, and site rendered-page tests
