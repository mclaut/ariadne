# Ariadne v0.8.30

The tray now explains itself: a local panel shows why the dot is yellow or red,
with logs and controls. Interrupted backups no longer pile up, and
consolidation uses the stronger curator when it is installed.

## Added

- **Ariadne panel.** To open it, choose "Open Ariadne panel…" (the new first
  menu item), click the warning row, or open Ariadne.app on macOS (for example
  by double-clicking it). It shows:
  - the dot color with a plain-language reason and every issue behind it;
  - Qdrant and Ollama state, record count and disk use;
  - the last 60 maintenance, consolidation and backup events, newest first;
  - tails of `maintenance.log`, `tray.log`, `update.log`, `capture.log` and
    `qdrant.err.log`, with secrets redacted;
  - the same start, stop, restart, maintenance and backup controls as the
    menu, plus shortcuts to the log and backup folders.

  The panel listens on `127.0.0.1` only, rejects any other `Host` header, and
  requires a random per-run token on every API call. The token travels in the
  URL fragment and an `X-Ariadne-Token` header. The page itself is static,
  under a strict Content-Security-Policy, and only the listed log files can be
  read.
- **Every color change is logged.** `tray.log` records each transition with
  its reasons, for example `health green -> red: Qdrant down`.

## Fixed

- **Interrupted full backups no longer leave their copy behind.** A full
  backup that failed or was killed after staging kept its unpublished
  `.pending-full-*` directory (about 15 GB each) forever. A failed run now
  removes its stage, and the next full or snapshot backup prunes abandoned
  stages of the same object under the operation lock. Only the numeric
  `MkdirTemp` suffix is matched, so restore-check stages are never mistaken for
  backup stages.
- **Consolidation progress after every batch.** Progress used to be recorded
  only after a whole diary group, so a very large group could pass the
  two-hour stuck threshold while working normally.
- **Linux maintenance can finish a long drain.** The systemd unit's
  `TimeoutStartSec` rises from 4h to 40h, above the application's own bounded
  retries.

## Changed

- **Stronger curator when installed.** With no `ARIADNE_CONSOLIDATION_MODEL`
  set, consolidation uses `qwen2.5:14b` whenever the local Ollama lists it.
  With `qwen2.5:7b`, the quality gate set aside 66 of 93 batches in one run.
  The model is part of the deferral key, so batches set aside by the smaller
  model are reconsidered once.

## Upgrade

Update from the tray. Memories, backups and settings are kept.

## Verification

Panel tests cover:

- rejection of foreign `Host` headers and of missing or wrong tokens;
- a page that carries no data, under a strict CSP;
- allowlisted log names, path traversal and secret redaction;
- action dispatch;
- color explanations;
- activity ordering.

Other new tests cover pruning of abandoned stages, the consolidation heartbeat,
local model detection and the launcher's loopback-only handle.

`go build`, `go vet` (darwin, linux, windows), `go test -race`,
`golangci-lint` v2.11.4 and `govulncheck` (0 reachable vulnerabilities) pass on
go1.26.11. The panel was also checked live against a running tray.
