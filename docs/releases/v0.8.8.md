# Ariadne v0.8.8

This release hardens optional remote Qdrant deployments, removes fixed
collection-scan limits, and keeps lifetime token-efficiency reporting fast
without sacrificing append-only recall history.

## Security

- **Fail-closed remote Qdrant policy.** Remote gRPC requires an API key and TLS;
  remote REST requires an API key and HTTPS. Loopback remains zero-config, and
  an explicit insecure override is reserved for a user-managed SSH or
  equivalent tunnel.
- **Secret-safe client configuration.** Long-running MCP, hook, maintenance,
  and tray launchers persist only the protected key-file path. Raw API keys are
  accepted only in process memory and are rejected by persistent installers.
- **Consistent installer propagation.** macOS launchd, Linux systemd/autostart,
  Windows Task Scheduler, Codex, and Claude receive the same non-secret Qdrant
  transport settings. Explicit Windows parameters override inherited self-
  update environment.

## Changed

- **Append-only metrics schema v3.** Raw recall events remain intact. A
  transactional daily rollup serves lifetime totals, and an index accelerates
  the exact recent-window query. Migration from v2 preserves raw row counts and
  computed totals.
- **Complete collection reconciliation.** `WingRoomPairs` uses paginated Qdrant
  scrolling rather than a fixed point limit, so large archival collections do
  not silently omit scopes.
- **Reusable maintenance retries.** Retry validation, bounded exponential
  backoff, cancellation-aware sleep, and lifecycle callbacks now live in
  `internal/maintenance`, while `ariadnectl` keeps its existing CLI, activity,
  and error semantics.

## Added

- **Judged retrieval evaluation.** `cmd/eval -retrieval-runs` reports macro
  Recall, MRR, and nDCG at explicit cutoffs for deterministic BM25 and learned-
  sparse comparisons. The included fixture is illustrative, not a performance
  claim.
- **Reversible repository cleanup.** `make clean` and `make clean-all` archive
  generated site artifacts with a recovery manifest instead of deleting them.
  A nested site Go module prevents root tooling from compiling Go sources
  carried by JavaScript dependencies.
