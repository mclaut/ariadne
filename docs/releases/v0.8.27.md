# Ariadne v0.8.27

A security maintenance release. Every shipped binary is rebuilt with a patched
Go toolchain and updated network dependencies, and releases can no longer be
built while a reachable vulnerability is known.

## Security

- Build with Go 1.26.11 instead of 1.26.2. This closes 24 reachable advisories
  in the Go standard library, including HTTP/2 server memory exhaustion and
  crashes, HTTP/1 connection desynchronization, TLS handshake and Encrypted
  Client Hello issues, distrust of compromised intermediate certificates, and a
  symlink root escape in `os`.
- Update `golang.org/x/net` to v0.63.0 and `google.golang.org/grpc` to v1.85.0,
  together with their `x/sys`, `x/text`, `genproto` and `protobuf` companions.
- The `install.sh` bootstrap now installs go1.26.11 by default (still
  checksum-verified; `ARIADNE_GO_VERSION` overrides it).

## Release gate

- CI and the release verification job run `govulncheck` v1.10.0. A reachable
  vulnerability fails the build, so a release cannot ship an affected standard
  library again.
- Go 1.27 is deferred: `govulncheck` cannot yet analyze its standard library,
  and moving would silently disable the scan.

## Known advisory

GO-2026-6911 affects the HTTP client in `mcp-go` and has no fixed version yet.
Ariadne serves MCP over stdio and does not reach that code; `govulncheck`
reports it at module level only.

## Upgrade

No data, configuration or behavior changes. Update from the tray or rerun the
installer; memories, backups and settings are kept.

## Verification

`go build`, `go vet`, `go test -race` across all 19 packages, `golangci-lint`
v2.11.4 and `govulncheck` (0 reachable vulnerabilities) pass on go1.26.11.
Native Windows/Linux CI gates publication.
