## What's new

- **Default-deny project recall.** Semantic `memory_recall` now requires a
  `wing`. Searching every project requires the explicit `all_wings: true`
  opt-in and is reserved for a user-requested cross-project audit. Exact-ID
  lookup remains available for deliberate curation.
- **Stable hook identity.** Session hooks resolve the nearest repository root
  instead of using the current directory basename. A repository-root
  `.ariadne-wing` marker can declare a stable namespace when directory names
  are ambiguous.
- **Credential ingress and egress guards.** MCP and store saves reject
  high-confidence private keys, credential URIs, known token formats, and
  explicit secret assignments. Import and capture redact matching values;
  consolidation validates output again; exact recall defensively redacts any
  matching payload.
- **Append-only secret quarantine.** `ariadnectl quarantine-secrets` scans
  curated and session collections without printing matched values. It is a
  dry-run by default. `--apply` marks records `quarantined`, preserves their
  original text and vectors, and records the previous status for a reversible
  audit trail. Normal recall always excludes quarantined points. An explicit
  `--reconcile` pass restores the previous status after detector refinement
  while retaining the quarantine history.
- **Agent filesystem isolation.** The shared Codex and Claude Code skill treats
  the active project as the filesystem boundary and explicitly forbids
  borrowing `.env` files, credentials, endpoints, IPs, or configuration from
  readable sibling projects.

## Compatibility and upgrade

- Existing memory payloads, vectors, IDs, snapshots, and historical statuses
  remain intact.
- Existing MCP clients must include `wing` on semantic recall. Clients that
  intentionally perform cross-project audits may send `all_wings: true`.
- Run `ariadnectl quarantine-secrets --collections ariadne,sessions` first to
  review metadata-only counts. Back up Qdrant before adding `--apply`.
- The `.ariadne-wing` marker is optional. Without it, hooks use the nearest
  repository root directory name as before.
