# Ariadne v0.8.14

This reliability release fixes the macOS tray updater handoff after a user
confirms an update.

## Fixed

- **The updater survives tray shutdown.** Before the tray exits, its helper
  now starts in an independent process session, allowing the downloaded
  installer to run after the menu-bar process is replaced.
- **The handoff is observable.** `update.log` records the helper start and PID
  before the tray exits, so a failed update no longer appears to do nothing.

## Compatibility

- Existing client settings, Qdrant data, backups, and previous versioned
  runtimes remain untouched by the update path.
- The installer still requires an explicit user confirmation in the tray.

## Verification

- focused tray updater tests
- full Go tests, build, lint, and site rendered-page tests
