# Ariadne v0.8.31

The tray stops raising false yellow alarms and notifying about one-second
blips, and nightly consolidation sets far fewer batches aside.

## Fixed

- **No false alarm when maintenance starts.** A deferred consolidation is a
  safe outcome, and maintenance records `complete_with_deferred` right after
  it. When the next run started, its `running` event did not count as a
  completion, so the tray showed "maintenance failed: consolidate: deferred"
  (and sent a notification) until the new run wrote its own consolidation
  event. A deferral is now settled by any newer maintenance event, and a
  standalone deferral reads as deferred work, never as a failure.
- **No notifications for one-second blips.** A metrics read that failed for a
  single poll, or a collection briefly yellow while Qdrant optimized, flipped
  the dot and sent a desktop notification within seconds. The tray now shows
  a new color only after two consecutive polls agree, and notifies when a
  worse color settles or a new set of issues persists. Its first poll still
  sets the icon at once, without notifying.

## Changed

- **Consolidation candidates are judged one by one.** Reviewed as a set,
  candidates about unrelated subjects from one diary were often rejected for
  being unrelated, which is not a defect; it was the reason for 15 of 28
  deferrals in one run with `qwen2.5:14b`. When the set review fails, each
  candidate is now judged alone and the set only for duplicates:
  - a candidate that really joins independent facts gets repair guidance to
    split it into separate memories;
  - duplicates get guidance to merge them;
  - the extra reviews run only after a set is rejected, so accepted sets cost
    nothing more.

## Upgrade

Update from the tray. The consolidation pipeline revision moves to
`atomic-v4`, so batches deferred by earlier releases are reconsidered once by
the next maintenance run. Memories, backups and settings are kept.

## Verification

Regression tests cover the previous run's deferral while the next run starts,
a standalone deferral, one-poll blips, settled changes and repeat
notifications, a persisting problem at tray start, unrelated candidates
accepted after individual review, the split repair of a mixed candidate, and
the merge repair of duplicates. `go build`, `go vet` (darwin, linux, windows),
`go test -race`, `golangci-lint` v2.11.4 and `govulncheck` v1.10.0 (0
reachable vulnerabilities) pass on go1.26.11.
