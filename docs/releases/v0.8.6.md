# Ariadne v0.8.6

This patch release makes approval prompts deterministic, restores reliable tray
restarts, reports service-control failures honestly, and keeps Claude Code's
persistent-memory workflow current across upgrades and context transitions.

## Fixed

- **Reliable supervised tray restart on macOS.** A managed tray now exits with
  an intentional restart status and lets `launchd` start exactly one replacement
  after the old menu-bar process has gone. This removes the race that could leave
  no tray icon after Restart or an update.
- **Honest service-control results.** `ariadnectl start`, `stop`, and `restart`
  now return non-zero when the platform service operation fails. The tray no
  longer reports success after a failed service command, including on Windows.
- **Approval copy matches the controls.** The warning help text no longer refers
  to the removed Later action.
- **Stale Claude integrations are repaired.** The installer now compares the
  installed skill with the shipped copy and validates the exact hook commands,
  matchers, and timeouts instead of treating any old `ariadne-hook` string or
  existing skill directory as current.

## Added

- **Persistent Claude memory after every context transition.** SessionStart
  recall now covers `startup`, `resume`, `clear`, `compact`, and `fork`.
- **Explicit in-context workflow guidance.** Auto-recall tells Claude to use
  Ariadne as persistent memory and immediately save durable decisions, gotchas,
  and verified outcomes instead of waiting for SessionEnd.
- **Regression coverage for desktop safety and upgrades.** Tests cover the
  supervised tray lifecycle, two-choice keyboard behavior, service error
  propagation, stale skill replacement, and exact Claude hook reconciliation.
- **Validated release tagging.** A release-request workflow creates a tag only
  from `main`, only when it matches the source version, and refuses to replace
  an existing tag.
- **Append-only release requests.** A committed request validates the source
  version, creates the annotated tag, and starts the release workflow without
  depending on a local GitHub credential.

## Changed

- **Approval requires a deliberate click.** System warnings expose exactly
  Approve and Deny. Neither is a default or focused action; Return/Enter and
  Escape do not approve, deny, or dismiss the request.
- **Claude hook registration is now an upsert.** Existing Ariadne entries are
  updated in place while unrelated user hooks remain untouched.
- **The shared Ariadne skill is mandatory for substantive work.** Its metadata
  now requires project-scoped recall at session start/resume and immediate
  durable saving when a stable result is reached.
- **Action-created tags explicitly dispatch the release workflow.** This avoids
  GitHub's recursive-workflow suppression for pushes made with `GITHUB_TOKEN`.

## Verification

- full build and `golangci-lint run`
- Windows and Linux cross-builds
- production site build and rendered-page tests
- live Claude MCP connection and SessionStart `startup`/`compact` hook checks
- working-tree, git-history, private-path, IP-address, and secret-pattern scans
